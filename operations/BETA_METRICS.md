# Beta Metrics

Track trends without collecting unnecessary personal data.

## Weekly metrics

- Release downloads
- New issues
- Confirmed bugs
- Open beta blockers
- Closed beta blockers
- Hardware reports
- Verified hardware configurations
- Documentation issues
- Average first-response time
- Duplicate issue rate
- Successful fresh-install reports
- Successful upgrade reports

## Quality indicators

- Installation success rate
- Reboot recovery success rate
- 24-hour stability pass rate
- Percentage of reports with complete hardware information
- Number of recurring support questions converted into documentation
- Number of regressions found before release

## Avoid

Do not request private location data, API keys, IP addresses, or unrelated system information solely for metrics.
