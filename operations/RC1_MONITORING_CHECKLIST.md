# RC1 Monitoring Checklist

During the first seven days after publishing RC1:

- Review new issues daily.
- Label regressions immediately.
- Check for secret exposure in reports.
- Track installation failures.
- Track upgrade failures.
- Track display-specific failures.
- Update known issues.
- Consolidate duplicates.
- Record hardware certification results.
- Pause stable-release planning if a beta blocker appears.
