# Known Issues

Use this document during public testing.

- Hardware support outside the primary Waveshare 13.3-inch Spectra profile may require community display profiles.
- Browser assets can remain cached after an upgrade; perform a hard refresh.
- Some diagnostics depend on Raspberry Pi OS services and may not appear in desktop-development environments.
- Beta testers should back up configuration before upgrading.

Add confirmed beta issues here and link each item to its GitHub issue.
