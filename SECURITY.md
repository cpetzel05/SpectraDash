# Security Policy

## Supported versions

Security fixes are prioritized for the latest public release and current pre-release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that exposes secrets, remote access, unsafe installation behavior, or private user data.

Report vulnerabilities privately to:

- Christopher Petzel
- cpetzel05@gmail.com

Include the affected version, impact, reproduction steps, and any suggested mitigation.

Do not include active credentials or unrelated private information.
