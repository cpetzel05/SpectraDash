# Sprint 7 Fresh Pi 4 Test

1. Install a clean Raspberry Pi OS image.
2. Update the Pi.
3. Clone the repository.
4. Run `sudo ./install.sh`.
5. Open port 8080 in a browser.
6. Confirm the mock provider loads.
7. Use Setup to select Open-Meteo and enter coordinates.
8. Render the display preview.
9. Confirm `/var/lib/spectradash/preview.png` exists.
10. Reboot and confirm the service returns.
11. Run `scripts/status.sh`.

Sprint 7 is preview-only and does not send commands to the physical panel.
