# SpectraDash Release Baseline

The application in this package is based directly on the uploaded and previously working `spectradash-8.0.0-rc18.1` release candidate.

No application source files were replaced by a separate rewrite. The existing architecture, display engine, web application, services, installer, plugins, themes, tests, and hardware support have been preserved.

Additional files in this package document the stable-baseline decision, rollback process, and incremental release policy.
