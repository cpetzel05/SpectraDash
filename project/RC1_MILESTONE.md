# v1.0.0-rc1 Milestone

## Scope

- Release blockers
- Confirmed regressions
- Installation failures
- Upgrade failures
- Hardware compatibility defects
- Documentation defects that prevent installation or recovery
- Security issues
- Data-loss issues

## Out of scope

- New layouts
- Major new features
- Large UI redesigns
- Experimental providers
- Breaking extension API changes

## Exit

- All blockers closed or explicitly deferred with documented rationale.
- Regression matrix complete.
- RC1 release published and observed publicly.
