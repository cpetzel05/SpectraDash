# GitHub Project Board Setup

Create a project named:

```text
SpectraDash Public Beta
```

## Recommended views

### Beta blockers

Filter:

```text
label:"beta-blocker" is:open
```

### Bugs

Filter:

```text
label:"bug" is:open
```

### Hardware validation

Filter:

```text
label:"hardware" is:open
```

### Documentation

Filter:

```text
label:"documentation" is:open
```

### v1.0 Stable candidates

Use a custom field named `Stable Candidate` with values:

- Yes
- No
- Needs review
