# Recommended Milestones

## v1.0.0-beta.1

Purpose: Publish the initial public beta and resolve immediate launch defects.

## v1.0.0-beta.2

Purpose: Consolidate early tester fixes, documentation improvements, and compatibility updates.

## v1.0.0-rc1

Purpose: Feature freeze and final release-candidate validation.

Exit criteria:

- No open beta blockers
- Primary hardware installation verified
- Scheduled refresh and reboot recovery verified
- Documentation reviewed
- Known issues documented
- Extension APIs clearly marked stable or provisional

## v1.0.0 Stable

Purpose: First stable public release.
