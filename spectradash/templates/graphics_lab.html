Spectra HD Graphics 2.0

Graphics comparison lab

Compare Standard, HD, and HD+ using the same forecast and layout. Generate previews first, then explicitly choose a mode to send to the e-paper panel.

Each image uses the six-color panel palette. HD renders icons at 2× resolution; HD+ uses 3× icon rendering and selective dithering. These are software previews: actual ink appearance can vary.

Previews are generated only when requested. On a Pi Zero 2 W this may take a while.

To keep a mode, open Settings and change Spectra rendering quality. Previews do not change settings. The Apply button saves the selected mode and requests a physical refresh.
