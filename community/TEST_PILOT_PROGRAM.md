# SpectraDash Test Pilot Program

The test pilot program invites Raspberry Pi and e-paper owners to validate installation, usability, and display compatibility.

## Ideal testers

- Owners of the verified 13.3-inch Spectra 6 panel
- Owners of experimental display profiles
- Pi Zero 2 W, Pi 4, and Pi 5 users
- New users willing to evaluate first-run instructions

## Test sequence

1. Record hardware and OS details.
2. Install from GitHub using the README.
3. Complete first-run setup.
4. Test preview-only mode.
5. Run the hardware test procedure.
6. Observe at least 24 hours of scheduled refreshes.
7. Submit a bug, feature request, or display compatibility report.

Never publish API keys, Wi-Fi credentials, exact home addresses, or unredacted support bundles.
