# Recommended GitHub Labels

| Label | Purpose |
|---|---|
| `bug` | Confirmed or suspected defect |
| `enhancement` | New feature or improvement |
| `documentation` | Documentation change |
| `hardware` | Display, Raspberry Pi, GPIO, or driver topic |
| `compatibility` | Hardware or operating-system compatibility |
| `needs-triage` | Awaiting initial review |
| `needs-info` | Reporter must provide more information |
| `confirmed` | Reproduced or sufficiently verified |
| `cannot-reproduce` | Not reproduced with supplied information |
| `duplicate` | Existing issue already tracks the problem |
| `beta-blocker` | Must be resolved before the next release stage |
| `good first issue` | Suitable for a new contributor |
| `help wanted` | Maintainers welcome assistance |
| `security` | Security-related tracking without sensitive details |
