# SpectraDash Development Status

SpectraDash has returned to the known-good `v1.0.0-rc1` baseline after a larger interface replacement introduced a web-service regression.

Future work will be released in small, testable increments. This approach improves reliability, makes regressions easier to identify, and provides a clear rollback path.

The project remains active. The next planned update is RC1.1, focused only on location and ZIP-code lookup.
