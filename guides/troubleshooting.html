Troubleshooting

Separate browser-rendering problems from physical-display problems.

Preview works, display does not

  • Confirm the display profile.
  • Run Test Physical Display.
  • Check power and cabling.
  • Review daemon heartbeat and logs.

Weather does not load

  • Run Test Weather API.
  • Verify provider credentials and location.
  • Check network and DNS.

Developer Mode appears incomplete

  • Hard-refresh the browser.
  • Verify the installed version.
  • Check /api/developer/status.
