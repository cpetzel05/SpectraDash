Installation

Install SpectraDash on Raspberry Pi OS.

Before beginning: Confirm your display model and use a stable power supply.

Requirements

  • Raspberry Pi Zero 2 W, 3, 4, or 5
  • Supported Waveshare Spectra display
  • Raspberry Pi OS
  • Network access

Install

git clone https://github.com/YOUR_USERNAME/SpectraDash.git
cd SpectraDash
sudo bash install.sh

First launch

  1. Open the web interface.
  2. Complete the Setup Wizard.
  3. Select the display profile.
  4. Render a browser preview.
  5. Test the physical display.
