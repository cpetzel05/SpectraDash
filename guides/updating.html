Updating

Back up configuration before changing beta versions.

  1. Record the current version.
  2. Back up configuration.
  3. Pull or extract the update.
  4. Rerun the installer.
  5. Hard-refresh the browser.
  6. Render a preview.
  7. Test the physical display.
cd ~/SpectraDash
git pull
sudo bash install.sh
