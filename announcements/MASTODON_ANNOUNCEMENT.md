SpectraDash v1.0.0-beta.1 is now available for public testing.

It is an open-source Raspberry Pi weather dashboard for Waveshare Spectra color e-paper displays, with forecasts, alerts, astronomy, themes, multiple layouts, browser previews, and diagnostics.

Primary target: Raspberry Pi Zero 2 W + Waveshare 13.3-inch Spectra 6.

https://github.com/cpetzel05/SpectraDash/releases/tag/v1.0.0-beta.1
