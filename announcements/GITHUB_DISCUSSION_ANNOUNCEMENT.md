# SpectraDash v1.0.0-beta.1 is now available

SpectraDash is an open-source Raspberry Pi weather dashboard designed for Waveshare Spectra color e-paper displays.

The first public beta includes Weather Station and Premium LCD layouts, seven-day forecasts, weather alerts, environmental data, realistic Moon rendering, astronomy, themes, a Setup Wizard, browser previews, and Developer Mode diagnostics.

The primary reference hardware is a Raspberry Pi Zero 2 W with the Waveshare 13.3-inch Spectra 6 / EL133UF1 display.

This beta is intended for installation, hardware compatibility, long-running stability, display synchronization, and documentation testing.

Please read the installation guide and known issues before starting. Report reproducible problems with the structured issue forms, and use Discussions for setup questions, ideas, and project showcases.

Never include API keys, passwords, private addresses, IP addresses, or other sensitive information in public reports.

Thank you for helping test SpectraDash.
