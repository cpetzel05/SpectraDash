# SpectraDash public beta — Raspberry Pi weather dashboard for Spectra e-paper

SpectraDash v1.0.0-beta.1 is now available for public testing.

The project turns a Raspberry Pi and compatible Waveshare Spectra color e-paper display into a configurable weather dashboard. It includes multiple layouts, seven-day forecasts, alerts, environmental information, astronomy, themes, browser previews, and built-in diagnostics.

Primary reference configuration:

- Raspberry Pi Zero 2 W
- Waveshare 13.3-inch Spectra 6 / EL133UF1
- Raspberry Pi OS

Testing on Raspberry Pi 3, 4, and 5 is especially welcome.
