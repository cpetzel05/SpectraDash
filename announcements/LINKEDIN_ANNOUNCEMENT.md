I am releasing the first public beta of SpectraDash, an open-source Raspberry Pi weather dashboard built for Waveshare Spectra color e-paper displays.

SpectraDash combines detailed forecasts, weather alerts, environmental data, realistic Moon rendering, astronomy, customizable themes, multiple layouts, browser previews, and system diagnostics.

The public beta is focused on installation quality, hardware compatibility, display reliability, and long-running stability.

Project: https://github.com/cpetzel05/SpectraDash  
Documentation: https://cpetzel05.github.io/SpectraDash/  
Beta release: https://github.com/cpetzel05/SpectraDash/releases/tag/v1.0.0-beta.1
