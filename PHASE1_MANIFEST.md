# RC18.3 Phase 1 Manifest

This package is based on the working RC18.2 application. Phase 1 changes repository presentation, documentation, community files, and GitHub templates. It does not intentionally modify the SpectraDash Python application, installer, uninstall script, services, tests, or display drivers.

## Primary additions

- Redesigned README and project banner
- User and developer documentation
- Display compatibility and tested hardware tracking
- Test Pilot Program and showcase guidance
- Bug, feature, and display-report issue forms
- Pull-request template and Discussions setup guide
