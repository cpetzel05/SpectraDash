# RC1 Security Review

- [ ] No API keys are committed.
- [ ] No passwords are committed.
- [ ] No private keys are committed.
- [ ] No Wi-Fi credentials are committed.
- [ ] Logs redact tokens and sensitive location data.
- [ ] Setup Wizard does not expose secrets in URLs.
- [ ] Configuration files use appropriate permissions.
- [ ] Web interface is not unintentionally exposed beyond the local network.
- [ ] Installer uses HTTPS for downloads.
- [ ] Update mechanism verifies integrity.
- [ ] Support bundles redact secrets.
- [ ] Dependency versions are reviewed.
- [ ] Security reporting instructions are current.
