# Hardware Compatibility Reporting

A useful hardware report includes:

- Raspberry Pi model and memory
- Display manufacturer and exact model
- Panel identifier
- Controller board or HAT revision
- Raspberry Pi OS version and architecture
- SpectraDash version
- Installation method
- Display profile used
- What worked
- What failed
- Required changes
- Photos when useful

Mark the result as fully working, working with limitations, or not working.
