# Public Testing Guide

Thank you for testing SpectraDash.

## Before testing

- Back up configuration.
- Record hardware and operating-system versions.
- Confirm the installed SpectraDash version.
- Use a stable power supply and network connection.

## Suggested tests

- Fresh installation
- Upgrade from the latest release candidate
- Weather Station and Premium LCD switching
- Theme rotation
- Fahrenheit and Celsius
- Weather alerts
- Astronomy information
- Browser preview
- Physical display refresh
- Network interruption and recovery
- Reboot recovery
- 24 to 72 hour continuous operation

## Reporting results

Use the issue templates and include sanitized logs or a support bundle. Photos of the physical display are especially useful for visual defects.
