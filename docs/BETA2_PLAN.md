# v1.0.0-beta.2 Plan

Beta 2 should contain fixes and documentation improvements from beta 1.

## Include

- Beta blockers
- Confirmed regressions
- Installation fixes
- Upgrade fixes
- Hardware-profile corrections
- High-value diagnostics
- Documentation corrections
- Safe performance improvements

## Defer

- Major new layouts
- Large architectural rewrites
- Experimental providers
- Unvalidated plugin API changes
- Cosmetic changes that risk regression

## Exit target

Beta 2 is successful when public testers can install or upgrade, operate the primary layouts, recover after reboot, and run for 24 hours without a blocking issue.
