# Stable Release Decision

RC1 may advance to v1.0.0 Stable only when:

- No open release blocker exists.
- No unresolved data-loss issue exists.
- No unresolved secret-exposure issue exists.
- Primary hardware passes the full RC1 regression matrix.
- Fresh installation passes.
- Supported upgrades pass.
- The 72-hour stability test passes.
- Known issues are documented.
- Installation and troubleshooting guides are verified.
- The public RC1 feedback period is complete.

Recommended minimum public RC1 observation period: 7 days.
