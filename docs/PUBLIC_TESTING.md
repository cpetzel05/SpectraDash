# SpectraDash Public Testing Guide

Thank you for testing SpectraDash.

## Before testing

1. Back up your current SpectraDash configuration.
2. Confirm the display model and Raspberry Pi model.
3. Record the installed SpectraDash version.
4. Use a stable power supply and network connection.

## Suggested tests

- Complete a fresh installation.
- Upgrade from the previous release candidate.
- Switch repeatedly between Weather Station and Premium LCD.
- Enable automatic theme rotation.
- Test Fahrenheit and Celsius.
- Trigger preview rendering from Developer Mode.
- Confirm weather alerts appear in both primary layouts.
- Leave the display running for at least 24 hours.
- Confirm refresh synchronization after network interruption or reboot.
- Export a support bundle if anything behaves unexpectedly.

## Reporting problems

Open a Bug Report and include:

- SpectraDash version
- Raspberry Pi model
- Display model
- Operating system version
- Layout and theme
- Reproduction steps
- Logs or Developer Mode support bundle
- A photo of the physical display when useful

Never publish API keys, Wi-Fi passwords, exact home addresses, or other private data.
