SpectraDash

A polished, themeable weather dashboard for Raspberry Pi and Waveshare Spectra e-paper displays.

Download Public testing

Premium themes

Weather Station and Premium LCD layouts with light, dark, and automatic appearance modes.

Rich weather data

Seven-day forecasts, alerts, air quality, UV, wind, pressure, astronomy, and trends.

Built for e-paper

Refresh management, watchdogs, display profiles, dithering, and hardware diagnostics.

Open and extensible

Theme packs, plugin SDK, developer tools, and community hardware profiles.

Quick start

git clone https://github.com/YOUR_USERNAME/SpectraDash.git

cd SpectraDash && sudo bash install.sh

Replace YOUR_USERNAME with the GitHub account that owns the repository.
