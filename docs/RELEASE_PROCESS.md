# Release Process

1. Freeze application changes for the candidate.
2. Run the full automated test suite.
3. Regenerate software previews.
4. Test fresh installation on supported Raspberry Pi hardware.
5. Verify upgrade and uninstall paths.
6. Confirm first-run setup contains no preset location.
7. Review documentation and links.
8. Generate checksums and release notes.
9. Tag the exact tested commit.
10. Publish the release as a pre-release until community validation is complete.
