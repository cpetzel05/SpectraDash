# First Run

New installations contain no preset city or ZIP code.

1. Open the SpectraDash web interface.
2. Complete the Setup Wizard.
3. Search for a city or ZIP code and confirm the matching location.
4. Select the exact display profile.
5. Choose units, layout, and refresh options.
6. Save the configuration.
7. Test the software preview before enabling physical output.

Weather downloads and scheduled display refreshes wait until a valid location has been saved.
