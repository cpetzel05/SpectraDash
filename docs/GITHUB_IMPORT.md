# GitHub Import Instructions

1. Upload `brand/`, `css/`, and `docs/` to the repository root.
2. Keep the existing project README; do not replace it with this package README.
3. Add this near the top of the project README:

```html
<p align="center">
  <img src="brand/readme/readme-hero.svg" alt="SpectraDash" width="100%">
</p>
```

4. In GitHub repository Settings, set the Social Preview using `brand/social/github-social-preview.svg`.
5. Add this favicon to the GitHub Pages `<head>`:

```html
<link rel="icon" href="/SpectraDash/brand/favicon/favicon.svg" type="image/svg+xml">
```
