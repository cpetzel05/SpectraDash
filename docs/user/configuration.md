# Configuration

SpectraDash configuration is managed through the web interface and local configuration files.

## Core settings

- Location and timezone
- Weather provider and credentials
- Temperature units
- Display profile
- Layout and theme
- Refresh interval
- Performance mode
- Theme rotation
- Alert visibility
- Astronomy and environmental panels

## Performance modes

### Auto

Selects behavior based on available hardware and active features.

### Full

Enables the highest-quality artwork and all supported panels. Recommended for more capable Raspberry Pi models.

### Lite

Reduces rendering cost and background processing. Recommended for lower-powered hardware or troubleshooting.

## Refresh interval

E-paper panels have different refresh requirements and limits. Use the recommended interval for the selected display profile.

## Theme rotation

Theme rotation can cycle through selected themes on a schedule. Test each theme individually before enabling rotation.

## Configuration backup

Before upgrades, copy the active configuration file and any custom themes, plugins, artwork, or display profiles.
