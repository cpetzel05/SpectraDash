# First-run Setup

The setup wizard guides new installations through the minimum configuration needed to render a dashboard.

## Display profile

Choose the exact display profile when available. The primary profile is the Waveshare 13.3-inch Spectra 6 / EL133UF1 configuration.

## Location

Use a city, postal code, or coordinates supported by the selected weather provider. Avoid publishing precise coordinates in screenshots or support reports.

## Weather provider

Enter the API key only in the local web interface. Never commit it to GitHub or paste it into public issues.

## Units

Choose Fahrenheit or Celsius. Unit changes should apply across primary layouts and queue a refresh.

## Layout and theme

Start with Weather Station or Premium LCD. Confirm rendering before enabling theme rotation.

## Final checks

- Weather API passes
- Browser preview renders
- Physical display test completes
- Scheduler is active
- Daemon heartbeat updates
