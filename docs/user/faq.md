# Frequently Asked Questions

## Is SpectraDash free?

Yes. SpectraDash is open-source software released under the MIT License.

## Which display is the primary target?

The reference configuration is the Waveshare 13.3-inch Spectra 6 display using the EL133UF1 panel.

## Does it work on Raspberry Pi Zero 2 W?

Yes. The Pi Zero 2 W is the primary Raspberry Pi target.

## Can I use Celsius?

Yes. Fahrenheit and Celsius are supported across the main layouts.

## Can I create my own themes?

Yes. SpectraDash includes a theme system and theme-development documentation.

## Can I add another display?

Potentially. Additional displays can be supported through display profiles and driver integration.

## Does the browser preview animate on the e-paper display?

No. Browser-only animation is for preview and configuration. The physical e-paper display renders static frames.

## Where should I report bugs?

Use the GitHub Bug Report template and include version, hardware, reproduction steps, and sanitized logs.
