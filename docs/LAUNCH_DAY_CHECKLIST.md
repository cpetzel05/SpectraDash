# Launch Day Checklist

- [ ] Publish `v1.0.0-beta.1` as a pre-release.
- [ ] Download and inspect the public release asset.
- [ ] Test the public installation path.
- [ ] Publish and pin the GitHub Discussion announcement.
- [ ] Confirm Issues and Discussions are enabled.
- [ ] Confirm the documentation site is online.
- [ ] Confirm repository social preview.
- [ ] Publish the first external announcement.
- [ ] Watch Issues and Discussions for installation blockers.
- [ ] Add confirmed issues to the known-issues document.
- [ ] Update announcements if a severe blocker is discovered.
- [ ] Record launch metrics after 24 hours.
