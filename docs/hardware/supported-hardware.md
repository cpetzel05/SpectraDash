# Supported Hardware

## Primary configuration

- Waveshare 13.3-inch Spectra 6
- EL133UF1 panel
- Raspberry Pi Zero 2 W
- Raspberry Pi OS

## Raspberry Pi models

| Model | Support level | Notes |
|---|---|---|
| Zero 2 W | Primary | Reference low-power configuration |
| 3 | Community | Expected to work with compatible drivers |
| 4 | Community | Good development and preview performance |
| 5 | Community | May require platform-specific adjustments |

## Displays

Display support depends on:

- Panel resolution
- Controller and driver
- GPIO or HAT interface
- Color model
- Refresh behavior
- Image conversion requirements

Use the hardware-report template to submit results for unlisted hardware.
