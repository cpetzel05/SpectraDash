# Before We Announce

## Product

- [ ] The tested release ZIP is final.
- [ ] Version numbers are consistent.
- [ ] Primary hardware completes installation.
- [ ] Browser previews work.
- [ ] Physical display refresh works.
- [ ] Scheduled refresh survives reboot.
- [ ] Fahrenheit and Celsius work.
- [ ] Weather alerts and astronomy are verified.
- [ ] Setup Wizard works from a clean configuration.

## Repository

- [ ] README hero and screenshots are final.
- [ ] No placeholders remain.
- [ ] No API keys or private information are present.
- [ ] License and contribution files are present.
- [ ] Issue forms work.
- [ ] Discussions are enabled.
- [ ] Repository validation passes.
- [ ] Social preview is configured.

## Documentation

- [ ] Installation guide tested from beginning to end.
- [ ] Upgrade guide tested.
- [ ] Troubleshooting guide includes real service and log commands.
- [ ] Hardware support claims match actual testing.
- [ ] Known issues are current.
- [ ] Download links work while logged out.

## Community

- [ ] Welcome Discussion is posted and pinned.
- [ ] Beta milestone exists.
- [ ] Public Beta project board exists.
- [ ] Labels are configured.
- [ ] Maintainer response templates are ready.
- [ ] Announcement links use the final public URLs.
