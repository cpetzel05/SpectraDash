# Display Configuration

Select the profile that exactly matches the display model and resolution. Do not select a profile only because its physical size is similar.

## Safe process

1. Choose the display profile in Settings.
2. Render and inspect the software preview.
3. Verify orientation and resolution.
4. Run the documented hardware test pattern.
5. Enable normal physical refresh only after the test succeeds.

The Waveshare 13.3-inch Spectra 6 profile is the verified reference profile. Other included profiles are community-testing candidates.
