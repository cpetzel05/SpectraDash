# Supported Hardware

## Primary target

- Waveshare 13.3-inch Spectra 6 / EL133UF1
- Raspberry Pi Zero 2 W

## Raspberry Pi compatibility

SpectraDash is intended to support:

- Raspberry Pi Zero 2 W
- Raspberry Pi 3
- Raspberry Pi 4
- Raspberry Pi 5

Actual performance depends on layout complexity, display driver support, memory, and operating-system configuration.

## Community testing

Hardware not listed above may work through display profiles. Please submit a Hardware Compatibility Report with detailed results.
