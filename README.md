# SpectraDash

A modern, themeable weather dashboard for Waveshare Spectra e-paper
displays powered by Raspberry Pi.

## Features

-   Premium LCD and Weather Station themes
-   Realistic Moon and astronomy
-   Weather alerts
-   Theme engine
-   Plugin support
-   Developer mode

## Installation

``` bash
git clone https://github.com/YOUR_USERNAME/SpectraDash.git
cd SpectraDash
sudo bash install.sh
```
