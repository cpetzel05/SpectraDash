# Governance

SpectraDash currently uses a maintainer-led governance model.

## Maintainer responsibilities

The project maintainer is responsible for:

- Release decisions
- Repository administration
- Security coordination
- Roadmap priorities
- Reviewing and merging contributions
- Maintaining project quality and community standards

## Contributors

Regular contributors may be invited to review code, triage issues, maintain documentation, or own specific subsystems.

## Decision making

Technical decisions should favor:

1. Reliability on supported hardware
2. Clear user experience
3. Backward compatibility
4. Maintainability
5. Extensibility through themes, plugins, and display profiles

Significant architectural changes should be discussed publicly before implementation unless security concerns require private coordination.
