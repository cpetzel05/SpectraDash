## Status definitions

- **Primary target:** Main reference configuration.
- **Verified:** Reproduced successfully by maintainers or multiple testers.
- **Community verified:** Reported working by community testers.
- **Partial:** Core functionality works with limitations.
- **Unsupported:** Known not to work or outside project scope.
