# RC1 Hardware Certification

A configuration may be listed as RC1 verified when:

- Fresh installation succeeds.
- Setup Wizard succeeds.
- Browser preview succeeds.
- Physical display refresh succeeds.
- Scheduled refresh survives reboot.
- Units can be changed.
- Main layouts render correctly.
- The system runs for at least 24 hours.
- No unresolved hardware-specific blocker remains.
