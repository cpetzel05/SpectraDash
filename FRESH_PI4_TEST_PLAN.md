# Fresh Raspberry Pi 4 Test Plan

1. Install a clean supported Raspberry Pi OS image.
2. Update the operating system.
3. Clone the SpectraDash repository.
4. Install the actual SpectraDash application.
5. Complete the Setup Wizard.
6. Test browser preview.
7. Test the Waveshare 13.3-inch Spectra 6 display.
8. Reboot.
9. Confirm services and scheduled refresh recover.
10. Disconnect networking for ten minutes.
11. Confirm automatic recovery.
12. Run for 72 hours.
13. Complete the RC1 test report.
