# RC1 Release Checklist

- [ ] Feature freeze is active.
- [ ] No new major features are accepted.
- [ ] All beta blockers are closed or explicitly deferred.
- [ ] Regression matrix completed.
- [ ] Primary hardware completed 72-hour test.
- [ ] Fresh installation tested.
- [ ] Upgrade from beta 1 tested.
- [ ] Upgrade from beta 2 tested.
- [ ] Known issues updated.
- [ ] Documentation reviewed.
- [ ] Version strings updated to `v1.0.0-rc1`.
- [ ] Release notes prepared.
- [ ] Release marked as pre-release.
- [ ] Public asset downloaded and retested.
