# SpectraDash v1.0.0-rc1

SpectraDash v1.0.0-rc1 is the first release candidate for the upcoming stable v1.0.0 release.

This build is feature-frozen. Testing should focus on reliability, installation, upgrades, hardware compatibility, documentation accuracy, and regressions.

## Highlights

- Weather Station layout
- Premium LCD Dark and Light layouts
- Seven-day forecast
- Weather alerts
- AQI, UV, dew point, pressure, wind, and precipitation
- Realistic Moon rendering and astronomy
- Setup Wizard
- Theme Gallery and automatic theme rotation
- Browser previews
- Developer Mode diagnostics
- Display-profile abstraction
- Plugin and community-theme foundations
- Fahrenheit and Celsius support

## Primary reference hardware

- Raspberry Pi Zero 2 W
- Waveshare 13.3-inch Spectra 6 / EL133UF1
- Raspberry Pi OS

## RC1 testing requested

- Fresh installation
- Upgrade from `v1.0.0-beta.1`
- Upgrade from `v1.0.0-beta.2`
- Configuration retention
- Browser preview rendering
- Physical display refresh
- Reboot recovery
- Network outage recovery
- Weather-provider outage recovery
- 72-hour continuous operation
- Raspberry Pi 3, 4, and 5 compatibility

## Reporting problems

Use the repository issue forms:

https://github.com/cpetzel05/SpectraDash/issues

Include the SpectraDash version, Raspberry Pi model, display model, operating system, steps to reproduce, and sanitized logs.

Never post API keys, passwords, tokens, private location data, or Wi-Fi credentials.

## Release status

This is a pre-release and may still contain defects. Back up existing configuration before installation or upgrade.
