# v1.0.0 Stable Exit Criteria

SpectraDash may be marked stable when all required criteria are met.

## Product

- [ ] Weather Station passes regression testing.
- [ ] Premium LCD Dark passes regression testing.
- [ ] Premium LCD Light passes regression testing.
- [ ] Fahrenheit and Celsius pass.
- [ ] Alerts pass.
- [ ] Astronomy and Moon rendering pass.
- [ ] Theme switching and rotation pass.
- [ ] Browser previews pass.
- [ ] Physical display refresh passes.

## Installation and upgrades

- [ ] Fresh installation passes on the primary hardware.
- [ ] Upgrade from beta 1 passes.
- [ ] Upgrade from beta 2 passes.
- [ ] Upgrade from RC1 passes if applicable.
- [ ] Configuration remains intact after upgrade.
- [ ] Recovery instructions are documented.

## Reliability

- [ ] Reboot recovery passes.
- [ ] Network outage recovery passes.
- [ ] Weather-provider outage recovery passes.
- [ ] 72-hour continuous run passes.
- [ ] No known data-loss issue.
- [ ] No unresolved security blocker.
- [ ] No open beta blocker.

## Documentation

- [ ] Installation guide is verified by a clean test.
- [ ] Configuration guide is current.
- [ ] Troubleshooting guide contains tested commands.
- [ ] Hardware matrix reflects verified results.
- [ ] Known issues are current.
- [ ] API and extension stability is clearly documented.

## Community

- [ ] Issue forms are working.
- [ ] Security reporting is documented.
- [ ] Contribution process is documented.
- [ ] At least one public beta feedback cycle is complete.
- [ ] Release notes and changelog are ready.
