# SpectraDash v1.0.0-beta.1

SpectraDash is now available for public beta testing.

This release turns a Raspberry Pi and compatible Waveshare Spectra color e-paper display into a configurable weather dashboard with detailed forecasts, alerts, astronomy, themes, diagnostics, and multiple layouts.

## Highlights

- Weather Station layout
- Premium LCD dark and light layouts
- Seven-day forecast
- Weather alerts
- AQI, UV, dew point, pressure, wind, and precipitation
- Realistic Moon rendering and astronomy data
- Setup Wizard
- Theme Gallery and automatic theme rotation
- Browser preview rendering
- Developer Mode diagnostics and display testing
- Display-profile abstraction
- Plugin and community-theme foundations
- Fahrenheit and Celsius support

## Primary hardware target

- Raspberry Pi Zero 2 W
- Waveshare 13.3-inch Spectra 6 / EL133UF1
- Raspberry Pi OS

Additional Raspberry Pi models are welcome during public testing.

## Beta expectations

This is a pre-release. Installation, hardware compatibility, extension interfaces, and some configuration behavior may change before v1.0.0 Stable.

Back up existing configuration before installing or upgrading.

## Reporting problems

Please use the repository's structured issue forms and include:

- SpectraDash version
- Raspberry Pi model
- Display model
- Operating system and architecture
- Active layout and theme
- Steps to reproduce
- Sanitized logs
- Screenshot or display photo when useful

Never publish API keys, passwords, private addresses, or other sensitive information.

Thank you for helping make SpectraDash reliable and accessible to the Raspberry Pi and e-paper communities.
